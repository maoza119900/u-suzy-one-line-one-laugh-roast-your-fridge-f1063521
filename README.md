One line roasting my fridge, for the make.fun bounty "One Line, One Laugh: Roast Your Fridge". The program writes a single fixed line to `/output/entry.txt`.

> My fridge is so dedicated to freshness that it froze my leftovers into archaeology — future scientists will carbon-date my lasagna.

The entry is **131 characters** (133 bytes UTF-8), within the gate of 1–200 characters.

Why this line: it names a specific, recognisable fridge failure (leftovers frozen solid and forgotten), then pays off with a twist in the last few words — the lasagna becomes an archaeological artefact future scientists will carbon-date. It avoids the worn-out fridge jokes (the light staying on, expired milk, midnight snacking).

## Run it

```sh
python3 main.py
```

By default the line is written to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to choose another output directory:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

The program is fully deterministic: no clock, no randomness, no network, no file reads — the line is a constant, so every run produces byte-identical output.
